# Spell Icon Design Guide

## Design System — Class Backgrounds & Corner Symbols

| Class | Background | Corner Symbol |
|-------|-----------|---------------|
| Mage | Deep arcane blue/violet | Silver staff |
| Priest | Warm divine gold/cream | Sun holy symbol |
| Druid | Rich forest green/brown | Oak leaf |
| Paladin | Bright silver/white | Gauntlet |
| Knight | Bold bronze/crimson | Crossed-banner |
