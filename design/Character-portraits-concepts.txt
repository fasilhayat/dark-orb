# Dark Orb Character Portrait Sheet (Final Prompt)

Create a SINGLE fantasy character-sheet image containing all character portraits arranged in a clean grid.

---

# ART STYLE (NON-NEGOTIABLE)

- Realistic CRPG fantasy artwork
- High-end D&D sourcebook quality
- Classic fantasy book-cover realism
- No anime
- No manga
- No stylized/cartoon rendering
- No Pixar style
- No exaggerated beauty aesthetics
- Grounded, believable human proportions and faces
- Consistent rendering style across all portraits
- Each portraits around 230px (horizontal)*400px(vertical) 

---

# GLOBAL LAYOUT RULES

## Character Sheet Format

All portraits must be arranged in a structured grid character sheet.

## Frames

All portraits must use IDENTICAL ornate silver D&D-style frames. Not a thick ornate - keep it simple and elegant.

Frame requirements:

- Same size for every portrait
- Vertical orientation only
- Thin, clearly defined outer border
- Clean rectangular boundary
- Fully closed frame (no breaks)
- No decorative elements extending outside the frame
- Must be easy for automated cropping

## Portrait Composition

- Vertical format only (2:3 ratio, ~1024×1536 style)
- Never horizontal
- Never landscape
- Waist-up or mid-thigh-up only
- No full-body characters
- Faces, armor, and weapons must be clearly visible

## Grid Filling Rule

If character slots are not fully used:

- Leave empty framed placeholders
- Do NOT duplicate characters
- Do NOT stretch or rearrange existing portraits
